# Ravi Pandey Portfolio

A simple static portfolio website for GitHub Pages.

## Files

- `index.html` - page structure and content
- `style.css` - styling and responsive layout
- `script.js` - mobile navigation and current year
- `assets/Ravi-Pandey-Resume.pdf` - resume download
- `assets/profile.jpg` - add your own photo here

## How to use

1. Copy these files into your `username.github.io` repository.
2. Add your photo at `assets/profile.jpg`.
3. Commit and push to GitHub.
4. GitHub Pages will serve the updated site.
